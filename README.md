## Hi, I'm Jerónimo

I build software that turns messy, manual processes into useful products. My work sits between **applied AI, automation, data products and interactive experiences**.

Currently I am studying Design and Digital Entertainment Engineering and building real tools with TypeScript, Next.js, Python, SQLite, n8n and local AI. I am also a co-founder of **DAZERIT**, a small software and automation studio in Medellín.
